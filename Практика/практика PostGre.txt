1.
Вывести список всех сотрудников (employees), 
которые родились в 1960 году или позже, 
отсортировав их по фамилии в алфавитном порядке.

SELECT employee_id, first_name, last_name, birth_date
FROM employees
WHERE birth_date >= '1960-01-01'
ORDER BY last_name ASC;


2.
Найти все активные продукты (products), 
у которых количество на складе (units_in_stock) меньше, 
чем уровень перезаказа (reorder_level), 
а поле discontinued равно 0.

SELECT product_id, product_name, units_in_stock, reorder_level
FROM products
WHERE units_in_stock < reorder_level AND discontinued = 0;


3. 
Посчитать общее количество заказов, 
оформленных каждым сотрудником. 
Вывести имя, фамилию сотрудника 
и количество его заказов.

SELECT e.employee_id, e.first_name, e.last_name, COUNT(o.order_id)
FROM employees e
JOIN orders o ON e.employee_id = o.employee_id
GROUP BY e.employee_id, e.first_name, e.last_name
ORDER BY COUNT(o.order_id) DESC;


4. 
Вывести названия категорий товаров (categories) 
и среднюю цену (unit_price) продуктов в каждой из них. 
Округлить среднюю цену до двух знаков после запятой и 
оставить только те категории, где средняя цена выше 20.

SELECT c.category_name, ROUND(AVG(p.unit_price)::numeric, 2) 
FROM categories c
JOIN products p ON c.category_id = p.category_id
GROUP BY c.category_name
HAVING AVG(p.unit_price) > 20
ORDER BY ROUND(AVG(p.unit_price)::numeric, 2) DESC;


5.
Для каждого заказа рассчитать его полную 
стоимость с учетом цены (unit_price), количества (quantity) 
и скидки (discount), а затем вывести 
топ-5 самых дорогих заказов за всю историю.

SELECT order_id,
ROUND(SUM(unit_price * quantity * (1 - discount))::numeric, 2) AS total_cost
FROM order_details
GROUP BY order_id
LIMIT 5;


6.
Используя оконные функции, ранжировать продукты внутри 
каждой категории по их цене (от самых дорогих к самым дешевым). 
Вывести название категории, название продукта, цену и его ранг.

SELECT c.category_name, p.product_name, p.unit_price, 
DENSE_RANK() OVER 
(PARTITION BY c.category_id ORDER BY p. unit_price DESC
) AS product_rank
FROM products p
INNER JOIN categories c ON p.category_id = c.category_id;


7. Вывести список клиентов (customers), 
у которых в поле contact_title содержится слово 'Manager', 
отсортировав их по названию компании (company_name).

SELECT customer_id,  company_name, contact_name, contact_title
FROM customers
WHERE contact_title LIKE '%Manager%'
ORDER BY company_name;


8. Найти общую сумму, которую каждый клиент потратил за все время 
(учитывая unit_price, quantity и discount в order_details). 
Вывести company_name и общую сумму, отсортировав от больших трат к меньшим.

SELECT c.company_name, ROUND(SUM(od.unit_price * od.quantity * 
(1 - od.discount))::numeric, 2) AS total_spent
FROM customers c
JOIN orders o ON c.customer_id = o.customer_id
JOIN order_details od ON o.order_id = od.order_id
GROUP BY c.customer_id, c.company_name
ORDER BY total_spent DESC;


9. Вывести список поставщиков (suppliers), 
от которых на данный момент нет ни одного активного продукта на складе 
(то есть units_in_stock = 0 для всех их продуктов).

SELECT supplier_id, company_name
FROM suppliers s
WHERE NOT EXISTS (SELECT 1 FROM products p 
					WHERE p.supplier_id = s.supplier_id
					AND p.units_in_stock > 0);


10. Посчитать количество заказов, оформленных в каждый год. 
Вывести год и число заказов. Отсортировать по хронологии.

SELECT EXTRACT(YEAR FROM order_date) AS order_year,
COUNT(order_id) AS total_orders
FROM orders
GROUP BY EXTRACT(YEAR FROM order_date)
ORDER BY order_year;
