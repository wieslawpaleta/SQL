1. Display the first and last names of all actors from 
the actor table in a single column in uppercase letters, 
named Actor Name.

SELECT UPPER(CONCAT(first_name, ' ', last_name)) AS `Actor name`
FROM actor;


2. Find the actor ID, first name, and last name of all actors
whose last name contains the letters GEN. 
Order the rows by last name, then first name.

SELECT actor_id, first_name, last_name
FROM actor
WHERE last_name LIKE '%GEN%'
ORDER BY last_name, first_name;


3. Find the total number of distinct actor last names 
present in the database. Then, write a query to show 
which last names appear more than once.

SELECT COUNT(DISTINCT last_name)
FROM actor;

SELECT last_name, COUNT(*) 
FROM actor
GROUP BY last_name
HAVING COUNT(*) > 1;


4. Calculate the total amount paid by each customer 
for all of their rentals. Display the customer's 
first name, last name, and the total amount paid, 
ordered alphabetically by last name.

SELECT c.first_name, c.last_name, SUM(p.amount) AS total_amount_paid
FROM customer c
INNER JOIN payment p ON c.customer_id = p.customer_id
GROUP BY c.customer_id, c.first_name, c.last_name
ORDER BY total_amount_paid ASC;  


5. List all film categories and the average running time 
(length) of films within each category. 
Display the category name and the average length, 
sorted from longest to shortest average runtime.

SELECT c.name AS category_name, AVG(f.length) AS average_length
FROM category c
INNER JOIN film_category fc ON c.category_id = fc.category_id
INNER JOIN film f ON fc.film_id = f.film_id
GROUP BY c.category_id, c.name
ORDER BY average_length;

7. Display the top 5 most popular films based on 
how many times they have been rented. 
Print the film title and the total rental count, 
ordered from most rented to least.

SELECT f.title AS 'Title', COUNT(r.rental_id) AS 'Total'
FROM film f
INNER JOIN inventory i ON f.film_id = i.film_id
INNER JOIN rental r ON i.inventory_id = r.inventory_id
GROUP BY f.film_id, f.title
ORDER BY COUNT(r.rental_id) DESC
LIMIT 5;


8. Find the total revenue generated by each staff member 
for the month of August 2005. Display the staff member's first name, 
last name, and total revenue, ordered from highest revenue to lowest.


SELECT s.first_name, s.last_name, SUM(p.amount) AS Revenue 
FROM staff s 
INNER JOIN payment p ON s.staff_id = p.staff_id
WHERE p.payment_date BETWEEN '2005-08-01 00:00:00' AND '2005-08-31 23:59:59'
GROUP BY s.staff_id, s.first_name, s.last_name
ORDER BY Revenue DESC;


9. List the top 5 countries with 
the highest number of active customers. 
Display the country name and the customer count, 
sorted from most to fewest customers.

SELECT COUNT(cu.customer_id) AS `Counter of customers`, co.country AS Country
FROM customer cu
INNER JOIN address a ON cu.address_id = a.address_id
INNER JOIN city ci ON a.city_id = ci.city_id
INNER JOIN country co ON ci.country_id = co.country_id
WHERE cu.active = 1
GROUP BY co.country_id, co.country
ORDER BY COUNT(cu.customer_id) DESC
LIMIT 5;


10. Identify all films that have a rental rate higher than 
the average rental rate of all movies in the database. 
Display the film title and its rental rate, 
ordered from highest rate to lowest.

SELECT title, rental_rate
FROM film
WHERE rental_rate > (SELECT AVG(rental_rate) FROM film)
ORDER BY rental_rate DESC, title ASC;


11. Write a query that classifies films into 
three duration categories using a CASE statement: 
Short (under 60 mins), Medium (60 to 120 mins), and Long (over 120 mins). 
Display the category and the total count of movies in that category.

SELECT 
CASE
    WHEN length < 60 THEN 'Short'
    WHEN length BETWEEN 60 AND 120 THEN 'Medium'
    ELSE 'Long'
END AS duration_category, COUNT(*) AS Total
FROM film
GROUP BY duration_category
ORDER BY total DESC;
