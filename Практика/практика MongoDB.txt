MongoDB sample_analytics.transactions 

1. Find the transaction details for 
the first account in your imported file (443178).

{ account_id: 443178 }


2. Find highly active accounts that 
have strictly more than 60 transactions (transaction_count).

{ transaction_count: { $gt: 60 } }  // $gt = greater than


3.  Look inside the nested arrays to find documents 
where a transaction involved Apple stock (aapl).

{ "transactions.symbol": "aapl" } // something like "WHERE" in SQL. 
                                  // "Znajdź mi dokumenty, 
                                  // w których wewnątrz obiektu (lub listy) 
                                  // transactions znajduje się pole symbol równe "aapl"."


4. Найдите все документы, у 
которых количество транзакций (transaction_count) 
строго больше или равно 95.

{ "transaction_count": { "$gte": 95 } }


5. Каждая транзакция внутри массива transactions 
имеет поле transaction_code (например, "buy" или "sell").
Условие: Найдите все аккаунты, 
у которых есть хотя бы одна операция по продаже ("sell").

{ "transactions.transaction_code": "sell" }


6. Выведите на экран только номер аккаунта (account_id) 
и количество транзакций (transaction_count). 
Стандартное поле _id нужно скрыть.

Project: { "account_id": 1, "transaction_count": 1, "_id": 0 }


7. Найдите все аккаунты, у которых количество транзакций 
(transaction_count) находится в диапазоне от 30 до 50 включительно.

{transaction_count: {"$gte": 30, "$lte": 50}}


8. Найдите документы, у которых количество транзакций 
(transaction_count) либо меньше 5, либо больше 98.

{ "$or": [ { "transaction_count": { "$lt": 5 } }, { "transaction_count": { "$gt": 98 } } ] }


9. Найдите аккаунты, у которых количество транзакций не равно 0.
{ transaction_count: { "$ne": 0} }


10. Найдите все документы, где в массиве transactions хотя бы 
в одной сделке участвовали акции Microsoft (символ: msft).

{ "transactions.symbol": "msft"}


11. Найдите аккаунты, у которых одновременно есть хотя бы одна операция покупки ("buy") 
и хотя бы одна операция продажи ("sell") внутри одного документа. 
(Подсказка: используйте оператор $all).

{ "transactions.transaction_code": { "$all": ["buy", "sell"] } }


12. Каждая транзакция внутри массива содержит поле стоимости или количества 
(например, amount). Попробуйте найти документы, 
где хотя бы одна транзакция имеет amount строго больше 5000.

{ "transactions.amount": { "$gt": 5000 } } 


13. Выведите список документов, содержащих только массив transactions, 
полностью скрыв account_id и системный _id.

Filter: {}
Options:
    Project: { "transactions": 1, "_id": 0 }

14. Выведите поля account_id и transaction_count, 
но при этом оставьте видимым стандартное поле _id.

Filter: {}
Options:
    Project: { "account_id": 1, "transaction_count": 1 }

    
15. Найдите документы для трех конкретных аккаунтов: 443178, 716662 и 557378.

{ "account_id": { "$in": [443178, 716662, 557378] } }


16. Найдите все документы, у которых дата начала периода 
(bucket_start_date) строго больше или равна 1 января 1990 года.

{ "bucket_start_date": { "$gte": ISODate("1990-01-01T00:00:00Z") } }


17. Найдите документы, в которых в массиве transactions нет 
ни одной сделки с акциями Apple (aapl) и Google (goog).

{ "transactions.symbol": { "$nin": ["aapl", "goog"] } }


18. Найдите аккаунты, у которых в массиве transactions 
содержится ровно 50 элементов (операций).

{ "transactions": { "$size": 50 } }

19. Найдите аккаунты, где количество транзакций (transaction_count) больше 80, а период (bucket_end_date) закончился до 1 января 2017 года.

{ 
  "transaction_count": { "$gt": 80 }, 
  "bucket_end_date": { "$lt": ISODate("2017-01-01T00:00:00Z") } 
}


20. Найдите документы, в которых есть хотя бы одна конкретная транзакция, где одновременно совершена покупка (transaction_code: "buy") И количество акций (amount) строго больше 9000.
Важно: Если написать просто два условия через запятую, MongoDB найдет документы, где одна транзакция — покупка, а другая — на сумму > 9000. Чтобы оба условия относились к одной и той же транзакции, нужен $elemMatch.

21. Найдите документы, у которых самая первая транзакция в массиве transactions (с индексом 0) была операцией продажи (sell).

22. Выведите все документы, отсортировав их по количеству транзакций (transaction_count) от большего к меньшему (по убыванию).

23. Найдите аккаунты с количеством транзакций меньше 20. Выведите только account_id и transaction_count (без _id), отсортировав по account_id по возрастанию.

24. Найдите все документы, в которых гарантированно присутствует поле bucket_start_date и оно не пустое ($ne: null).
